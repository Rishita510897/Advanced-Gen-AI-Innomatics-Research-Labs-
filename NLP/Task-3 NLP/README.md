🤖 Chatbot using Transformers

Objective
Build a conversational chatbot using Hugging Face Transformers.

Technologies Used
Python
Hugging Face Transformers
PyTorch

Features
Uses DialoGPT model
Maintains conversation context
Generates human-like responses
Supports continuous conversation
Exit using 'exit' or 'quit'

🔄 Workflow

User Input → Model → Response Generation → Output
